# US Healthcare Claims Lifecycle - Interactive Documentation

Welcome to the comprehensive guide on the US healthcare system, claims processing, and healthcare compliance. This documentation is designed to be interactive, practical, and includes real-world examples throughout.

## 📚 Course Overview

This course covers the complete lifecycle of US healthcare claims, from member enrollment to claims adjudication, with deep dives into compliance, coding standards, and EDI transactions.

### Target Audience
- Healthcare professionals
- Insurance professionals
- Medical coders and billers
- Healthcare IT specialists
- Compliance officers
- Students entering healthcare industry
